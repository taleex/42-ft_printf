# Libft

## Description

The goal of this project is to recreate a collection of standard C library functions, along with additional utility functions.

Through this project, I developed a deeper understanding of C programming, memory management, pointers, string manipulation, and data structures.

The project is divided into three main sections: Libc Functions, Additional Functions, and Linked Lists.

---

### Main Files

| File | Description |
| --- | --- |
| [libft.h](./libft.h) | Contains standard library header inclusions, function prototypes, and custom data structure definitions used throughout the library. |
| [Makefile](./Makefile) | Defines compilation rules and library management commands. |
| libft.a | Compiled static library generated by the Makefile. |

| Function | Description |
| --- | --- |
| [`ft_isalpha`](./ft_isalpha.c) | Checks if a character is alphabetic. |
| [`ft_isdigit`](./ft_isdigit.c) | Checks if a character is a digit (0-9). |
| [`ft_isalnum`](./ft_isalnum.c) | Checks if a character is alphanumeric. |

| [`ft_isprint`](./ft_isprint.c) | Checks whether the character (integer passed) falls within the ASCII range of printable characters (32-126). |
| [`ft_strlen`](./ft_strlen.c) | Calculates the length of a string. |
| [`ft_memset`](./ft_memset.c) | Fills the first n bytes of a memory area with a specified byte. |

| [`ft_memcpy`](./ft_memcpy.c) | Copies n bytes from a source memory area to a destination. |
| [`ft_memmove`](./ft_memmove.c) | Copies a block of memory, handling overlapping areas safely. |
| [`ft_strlcpy`](./ft_strlcpy.c) | Copies a string to a buffer with size checking. |
| [`ft_strlcat`](./ft_strlcat.c) | Concatenates a string to a buffer with size checking. |
| [`ft_toupper`](./ft_toupper.c) | Converts a character to its uppercase equivalent. |
| [`ft_tolower`](./ft_tolower.c) | Converts a character to its lowercase equivalent. |
| [`ft_strchr`](./ft_strchr.c) | Locates the first occurrence of a character in a string. |
| [`ft_strrchr`](./ft_strrchr.c) | Locates the last occurrence of a character in a string. |
| [`ft_strncmp`](./ft_strncmp.c) | Compares at most n characters of two strings. |
| [`ft_memchr`](./ft_memchr.c) | Scans memory for the first occurrence of a character. |
| [`ft_memcmp`](./ft_memcmp.c) | Compares two blocks of memory. |
| [`ft_strnstr`](./ft_strnstr.c) | Locates a substring within the first 'n' bytes of a string. |
| [`ft_atoi`](./ft_atoi.c) | Converts a string to an integer. |
| [`ft_calloc`](./ft_calloc.c) | Allocates memory for an array and initializes it to zero. |
| [`ft_strdup`](./ft_strdup.c) | Duplicates a string by allocating new memory. |

## Instructions

| Command | Purpose |
| --- | --- |
| `make` | Compiles the library. |
| `make all` | Compiles the library. |
| `make clean` | Removes object files. |
| `make fclean` | Removes object files and the compiled library. |
| `make re` | Cleans and recompiles the library. |

When the library is generated, a `libft.a` file is created.

### Main (Optional)

For testing purposes, you can add the following lines to the Makefile:

```make
main:
	$(CC) $(CFLAGS) main.c -L. -lft -o test

clmain:
	$(RM) test
```

This will provide an easy and quick way to compile the main file. See the examples below:

```sh
make main
./test
make clmain
```
